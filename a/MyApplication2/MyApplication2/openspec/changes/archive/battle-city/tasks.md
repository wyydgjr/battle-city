# Tasks: Battle City Implementation Plan (MVP 聚焦版)

## 阶段1：基础四区布局与渲染框架（优先级：最高）
- [x] T001 - 创建项目与全屏沉浸式配置
  - 描述：初始化HarmonyOS项目，配置竖屏锁定，隐藏状态栏与导航栏
  - 前置：无
  - 工时：0.5天
  - 验收：应用全屏运行，无系统UI干扰，逻辑分辨率为360×780vp

- [x] T002 - 实现四区基础布局与自适应缩放
  - 描述：按照10%(信息)+60%(游戏)+20%(操控)+10%(菜单)划分屏幕，计算并存储微缩格子(9.23vp)的全局缩放系数
  - 前置：T001
  - 工时：1.5天
  - 验收：四个区域占比正确无黑边，游戏区呈现正方形无拉伸，不同分辨率下自适应

- [x] T003 - 实现Canvas渲染管线与像素风配置
  - 描述：创建GameRenderer类，开启60FPS循环，关闭抗锯齿(imageSmoothingEnabled=false)
  - 前置：T002
  - 工时：1天
  - 验收：能绘制黑色背景与测试网格，帧率稳定，线条呈现清晰像素锯齿

## 阶段2：微缩地图与场景交互（优先级：高）
- [x] T004 - 实现微缩地图系统与细分格子
  - 描述：创建GameMap类，实现39×39微缩格子，将原版砖墙细分为4个独立1×1小块，支持轰开角落后留下半截墙的机制
  - 前置：T003
  - 工时：2天
  - 验收：能正确渲染细分后的地图，子弹击中砖墙上半部只摧毁上半部，下半部保留

- [x] T005 - 实现前三关关卡数据
  - 描述：设计并录入3个基础关卡数组，包含空地、细分砖墙、钢墙、基地等
  - 前置：T004
  - 工时：1天
  - 验收：前三关地图数据加载无报错，基地在底部中央被砖墙保护

- [x] T006 - 实现场景静态碰撞与边界检测
  - 描述：实现坦克与地图格子的碰撞阻挡，子弹与钢墙/砖墙的碰撞销毁逻辑
  - 前置：T004
  - 工时：1.5天
  - 验收：坦克不能穿墙，子弹击中砖墙摧毁对应小块，击中钢墙子弹消失

## 阶段3：核心坦克与操控手感（优先级：高）
- [x] T007 - 实现微缩坦克基类与1格占位渲染
  - 描述：创建Tank抽象类，尺寸设定为1×1格(约9.23vp)，实现像素风绘制，坦克坐标对齐微缩格子
  - 前置：T003, T004
  - 工时：1.5天
  - 验收：能在地图上渲染1格大小的玩家与敌方坦克，无模糊渲染

- [x] T008 - 实现虚拟摇杆与发射按钮
  - 描述：在20%操控区实现多点触控，左侧摇杆响应八向移动并输出方向向量，右侧发射按钮响应点击
  - 前置：T002
  - 工时：2天
  - 验收：摇杆跟手无延迟，支持摇杆移动同时点击发射，触控热区正确不误触

- [x] T009 - 实现玩家坦克移动与钻墙机制
  - 描述：处理摇杆输入，实现坦克转向与移动。**核心**：优化碰撞箱，当砖墙被轰开1格空间时，玩家坦克能平滑挤入该1格空隙
  - 前置：T007, T008, T006
  - 工时：2天
  - 验收：操控流畅，能明显体验到轰开墙角后钻过去的原版微操感

- [x] T010 - 实现子弹系统
  - 描述：实现Bullet类，处理发射冷却、飞行、越界销毁
  - 前置：T007, T008
  - 工时：1天
  - 验收：按发射键能向当前朝向发射子弹，同屏最多1颗

## 阶段4：简单战斗与流程闭环（优先级：中）
- [x] T011 - 实现基础敌方AI与防重叠机制
  - 描述：实现EnemyTank，基础移动逻辑（遇墙换方向，随机射击）。**核心**：生成和移动时检测与其他坦克的AABB碰撞，若重叠则换方向或延迟生成
  - 前置：T007, T006
  - 工时：2天
  - 验收：敌方坦克不会叠在一起，能自动巡逻和开火

- [x] T012 - 实现坦克击毁与胜负判定
  - 描述：子弹击中敌方扣血/爆炸，击中玩家减命，击中基地Game Over。实现简单的2帧像素爆炸效果
  - 前置：T010, T011
  - 工时：1.5天
  - 验收：能消灭敌方，玩家被击中能重生，基地被毁触发失败

- [x] T013 - 实现顶端信息与底端菜单交互
  - 描述：10%信息条实时显示得分与生命值；10%菜单栏实现【重新玩】(重置当前关)和【返回主页】(切换至标题页)功能
  - 前置：T002, T012
  - 工时：1天
  - 验收：得分随击杀增加，按钮点击响应正确，状态切换无异常

- [x] T014 - 基础音效与前三关联调测试
  - 描述：加入移动、射击、爆炸的基础音效，对前三关进行整体流程测试，修复微缩格子带来的卡墙bug
  - 前置：T012, T013
  - 工时：2天
  - 验收：前三关流程通畅，操控舒适，无恶性卡顿或穿模bug
